# IMAPSwap Release

![ImapSwap Logo](imapswap.png)

IMAPSwap is a tool developed by [StrapMail](https://www.strapmail.com/) to help you take back control of your emails.


It allows you to migrate emails between IMAP servers, giving you the freedom to choose where your emails are hosted and keeping control of your data.

## Downloads

Download the latest version of IMAPSwap from the [Releases](https://github.com/exostrive/imapswap-release/releases) page.
